# Real World Talk

A live-action, Egyptian-Arabic speech-development app for children aged 2–3.5 (working repo: `yassin-reels`).

**Stage: pre-production. No code until sections 9 and 10 of the brief are approved.**

## First deliverable (brief §13)

| | Document | What it contains |
|---|---|---|
| A | [Language map](docs/A-language-map.md) | 66 sentence ladders × 4 levels, ranked, with module, perspective, gender forms and source. Data: [`data/ladders.csv`](data/ladders.csv) |
| B | [Content matrix, ladders 1–20](docs/B-content-matrix-ladders-01-20.md) | 80 clips: on-screen action, exact audio sequence, pause and expected response |
| C | [Pilot shot list](docs/C-pilot-shot-list.md) | 30 clips: setup, talent, framing, action, audio, hold, length + shoot-day running order |
| D | [Production plan](docs/D-production-plan.md) | Crew, equipment, stock licensing, voice recording, legal, cost and calendar to the pilot; v1 forecast |
| E | [Risks and recommended changes](docs/E-risks-and-recommended-changes.md) | The three biggest risks and ten proposed changes to the brief |

## Decisions needed before the next step (shot list → clickable prototype)

1. Accept or reject the changes in doc E (especially: co-viewing as the core, segment-based audio, POV filming, TEMPTATION clip type, 4–6-year-old child actors).
2. Name the SLP advisor.
3. Lean or recommended pilot budget (doc D §6).
